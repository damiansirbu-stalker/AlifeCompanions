# AlifeCompanions: Custom companions for STALKER Anomaly

Companions with no quest requirements, recruited by talking to them.
Each one has their own location, personality and terms, and permadeath applies, so a companion who dies stays dead.

[Releases](https://github.com/damiansirbu-stalker/AlifeCompanions/releases) | [Bugs, suggestions](https://github.com/damiansirbu-stalker/AlifeCompanions/issues)

[![validate](https://github.com/damiansirbu-stalker/AlifeCompanions/actions/workflows/validate.yml/badge.svg)](https://github.com/damiansirbu-stalker/AlifeCompanions/actions/workflows/validate.yml) [![Project Health](https://img.shields.io/badge/project_health-dashboard-00ced1)](https://damiansirbu-stalker.github.io/AlifeCompanions/)

Requires: Anomaly 1.5.3, modded exes (themrdemonized or AOEngine), [xlibs](https://www.moddb.com/mods/stalker-anomaly/addons/xlibs-1001), MCM. Exact versions in [readme.txt](doc/readme.txt).
